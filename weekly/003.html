第3回 2026年6月9日（火） 🤖 AI活用

CoworkとAsanaで「管理」を変える
— 自分にも、チームにも使えるAI × PMツール活用

Cowork Asana マネジメント 自己管理 AI活用

📌 今回取り上げたもの

タスク管理ツールとしてAsanaを使いながら、AIアシスタントのCoworkと組み合わせると何が変わるか——を整理した。 「マネジメント」というと他者管理のイメージが強いが、今回は自分自身のタスクと仕事の流れを管理する「セルフマネジメント」と、チームや他者への「タスクアサイン・進捗把握」の両面から考えた。

自分自身は現在Cowork＋Asanaを使って日々の業務管理を試みているが、まだ最大限に活かせているかは正直わからない。 その「使ってはいるが、うまく使い切れていない」という実感も含めて書く。

📝 CoworkとAsanaを組み合わせると何が変わるか

通常のAsana操作は「アプリを開く → プロジェクトを探す → タスクを作成 → フィールドを埋める」という手順を踏む。 CoworkがAsanaのMCP（連携）を通じて使えるようになると、この手順がほぼ会話に置き換わる。

Asana UIを開く
→
プロジェクトを探す
→
タスク作成・入力
「〇〇のタスク作って」と話す
→
Coworkが即座にAsanaへ反映

ポイントは「UIを経由しない」ことではなく、「今いる文脈（会話）からそのまま行動できる」こと。 ブラウザを切り替えて操作するというコンテキストスイッチがなくなる。

🙋 セルフマネジメント

  • 「今日のタスクを教えて」→ Asanaから一覧取得・要約
  • 「〇〇は完了にして」→ 会話の流れで即ステータス更新
  • 「今週中に△△をやる」→ タスク作成・期限設定
  • 「優先度の高いものから並べて」→ AIが解釈して整理

👥 他者・チームへの管理

  • 「〇〇さんに△△を依頼して」→ Asanaでアサイン
  • 「プロジェクトXの進捗まとめて」→ 複数タスクを横断で確認
  • 「今週の完了タスクをリストアップ」→ 週次レポートの素材を即生成
  • 「期限切れのタスクを抽出して」→ Coworkが一覧化

特に他者管理の文脈では、「複数人・複数プロジェクトにまたがる情報を人間が集めて整理する」という作業が最も時間を食う部分で、ここにCoworkを差し込む価値は大きい。 人間が苦手な「横断的な情報の集約」をAIに任せられる。

USER → COWORK
今週期限のタスクのうち、まだ未完了のものを担当者ごとにまとめて
COWORK → ASANA → USER
Asanaから取得した結果：田中さん（2件）、佐藤さん（1件）… ← こういう応答が返ってくる

💡 自分の考え・業務への活用案

使ってみて感じるのは、「ツールを使う習慣」より「ツールに話しかける習慣」の方が定着しにくい、ということ。 Asanaを開いてタスクを作る動作は身体化されているのに、「Coworkに頼む」という動作はまだ脳が迷子になる。 これは技術の問題ではなく、行動パターンの書き換えに時間がかかるという話だと思っている。

ただ、一度このパターンが定着すると強いと思う理由がある。 会話そのものが管理の記録になる点だ。「〇〇を依頼した」「〇〇は来週に延ばすことにした」という判断の経緯がCoworkとのチャットに残り、AsanaのタスクIDとセットで参照できる。 Asanaには「何をやるか」が残り、Coworkには「なぜそう決めたか」が残る構造になる。

課題も正直に書くと、Coworkの回答の精度はAsanaのデータの質に完全に依存する。 タスクの粒度がバラバラだったり、担当者や期限が抜けていたりすると、Coworkがどれだけ賢くても正しい整理はできない。 「AI × PM」の効果を上げたければ、まずAsana側のデータを整えることが前提になる。

業務への活用として現実的だと感じる入り口は、週の始まりに「今週のタスク一覧を出して、優先度で並べて」と聞くことを習慣化することだと思っている。 朝の計画立てに10分かけていたものが、会話1往復で完結するようになれば、それだけで十分な価値がある。
